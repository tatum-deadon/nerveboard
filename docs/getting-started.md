# Getting Started

## Installation

```bash
pip install nerveboard
```

## Show Dashboard

```bash
nerveboard dashboard --repo ./my-project
```

## Generate Report

```bash
nerveboard report
```

## Understanding Metrics

- **Commits**: Total commits in the period
- **Contributors**: Active developers
- **Velocity**: Commits per day trend
- **Coverage**: Test coverage percentage

## Tips

1. Run `nerveboard dashboard` daily for quick standup context
2. Use `nerveboard report` for weekly team reviews
3. Export data with the Python API for custom analysis
